## Primary implemented gameplay promise

`scalable_tnt:low_yield_tnt` and `scalable_tnt:high_yield_tnt` are craftable/placeable TNT blocks with vanilla `PrimedTnt` fuse/entity behavior but tagged blast powers **3.0** and **4.5**, respectively, against vanilla TNT's usual **4.0**. `ScalableTntBlock` primes via redstone, fire/explosion, player flint-and-steel/fire-charge, fiery projectile and a registered dispenser behavior; successful insertion removes/consumes the source where applicable. `PrimedTntExplosionMixin` modifies the native explosion-power argument only for primed entities carrying the mod's float tag, bounds that value to [3.0, 4.5], and leaves untagged TNT's native argument alone. This is source behavior, not observed radius, persistence, coexistence, or multiplayer proof. See `ScalableTntMod.java`, `block/ScalableTntBlock.java`, `block/ScalableTntContent.java`, `policy/TntComposition.java`, `mixin/PrimedTntExplosionMixin.java` and `scalable_tnt.mixins.json` under `src/main`.

## Acquisition and recipe roots

- Block items and blocks: `ScalableTntContent.LOW_YIELD_*` / `HIGH_YIELD_*`, registered as `scalable_tnt:low_yield_tnt` and `scalable_tnt:high_yield_tnt`; both block items are offered in the Redstone Blocks creative tab (`ScalableTntMod.addCreativeItems`). Names are in `src/main/resources/assets/scalable_tnt/lang/en_us.json`.
- `src/main/resources/data/scalable_tnt/recipes/low_yield_tnt.json`: shapeless **six `#kubejs:ordinary_sand` + three `minecraft:gunpowder`** → one low-yield TNT. `high_yield_tnt.json`: **three `#kubejs:ordinary_sand` + six `minecraft:gunpowder`** → one high-yield TNT. The sand tag is a **pack-side dependency**, not defined in this repository; check its definition, actual obtainable members and recipe visibility/craftability in the selected full-pack pair. Gunpowder acquisition depends on the assembled pack/world. Neither recipe is a substitute for an in-world acquisition/GUI check.
